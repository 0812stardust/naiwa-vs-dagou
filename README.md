# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.2**。

## 玩法
- **P1**：A/D 移动 · W 跳跃 · S 蹲防 · J 普攻 · K 大招 · M 放炸弹 · ESC 暂停
- **双人对战**：P2 使用 ← → ↑ ↓ 移动/跳跃/蹲防，`-` 普攻，`=` 大招，`[` 放炸弹
- **地图**：🌿 草地（无特殊效果） / ❄️ 雪地（所有移速 -20%）
- **掉落物 6 种**：💣 炸弹（3 秒后爆炸，可放置）、🛡 护盾（5 秒/免一次伤害）、❤ 红心（+1 命）、💉 血包（+30HP）、⛓ 锁链（定身 3 秒）、🛹 滑板（7 秒移速×2）；掉落物 5 秒未拾取自动消失
- **键位设置**：主菜单 → 设置 → 键位设置，点击动作后按键即可修改，冲突会提示，自动保存到 localStorage
- **昵称登录**：首次进入输入昵称，可随时在菜单修改
- **暂停菜单**：继续 / 背景音乐音量 / 音效音量 / 退出
