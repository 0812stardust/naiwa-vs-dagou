# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.84**。

## v0.84 更新
- **修复：角色对战变成纯色方块**：贴图加载失败时自动重试（最多 3 次、带时间戳参数绕过坏缓存），解决 github.io 网络抖动/缓存坏响应导致角色显示为绿/橙方块的问题
- **兜底美化**：即使某张贴图最终仍加载失败，也以「圆角角色卡片 + 表情」绘制，不再出现生硬的纯色方块

## v0.83 更新
- **攻击手感丝滑化**：普攻/大招命中不再顿帧（仅爆炸保留 4 帧、击杀保留慢动作）；攻击中可移动且移速不变；攻击任意时刻可跳跃取消；攻击活跃帧内锁定向朝（防挥击翻面）
- **人机跨层寻路重写**：按“可站立面 + 跳跃可达性”导航上/下平台，目标固定带迟滞防震荡——消除玩家在上层时反复左右转向的荒诞场景；高层不可达时改为在玩家正下方待机，不再空跳
- **炸弹投掷机制**：M（P1）/`[`（P2）由原地放置改为朝面前投掷（抛物线、落地/触台/引信爆炸）；人机会主动逼近投弹并在引信将尽时强制出手、投后后撤，不再持弹自爆

## v0.82 更新
- **结算界面全面美化**：死亡后先播放简短 KO 时刻，随后弹出与开始界面同风格的「对局结算」面板
- **结算按钮化**：「🔁 再来一局」「🏠 返回主菜单」做成按钮置于结算卡片中（键盘 R/M 仍可用），四套主题均适配
- **结算内容**：胜者圆形头像（角色立绘）、胜方提示、伤害/最高连击/拾取/击杀/本局得分/对局时间明细，双人模式分列 P1/P2

## v0.6 新内容
- **空中攻击 / 下砸**：空中按 J 出空中攻击，空中 S+J 下砸俯冲
- **受身系统**：被击飞后按跳跃键翻滚脱身（带短暂无敌）
- **能量条大招**：命中/受击积攒能量，满 100% 才能放大招，节奏更有策略性
- **攻击后坐力**：普攻类后坐力 ×3、大招 ×5
- **结算统计页**：胜负后显示伤害/连击/拾取/击杀/得分明细 + 胜者特写
- **新手引导**：首次战斗显示按键提示动画
- **AI 用道具**：大狗会主动捡护盾/血包/炸弹并会用炸弹
- **训练模式增强**：木桩可切换站桩/反击/移动，并显示累计伤害
- **连击层级**：5/10/15 连击音效与特效逐级增强
- **虚空边界修复**：越过地面边缘立即坠入虚空死亡，不再能退回

## v0.8 更新

- **战斗规则**：连段伤害逐击衰减（最低50%）、击飞落地倒地保护（10帧倒地+24帧保护）、受身可脱离倒地

- **选角全面化**：人机/双人/训练都可自由选角（注册表驱动，为第 3 角色铺路）

## 玩法
- **虚空边界**：地图两端为虚空（与背景同色、无黑边），地面在边缘截止，被击退或走出边界会坠入虚空死亡并重生；视野可延伸至虚空
- **打击感增强**：击杀时目标被击飞、攻击者受到后坐力，命中带火花与受击白闪
- **P1**：A/D 移动 · W 跳跃（奶蛙可二段跳）· S 蹲防 · J 普攻 · K 大招 · M 放炸弹 · ESC 暂停
- **双人对战**：P2 使用 ← → ↑ ↓、`-` 普攻、`=` 大招、`[` 放炸弹
- **多层地图**：四张地图均有平台与箱子，可跳上跳下、走出平台边缘下落（已移除梯子与蹦床）
- **角色差异化**：奶蛙=快攻+空中二段跳；大狗=高攻+击退强化+每 15 秒一次暴击（伤害 +50%），双方血量均 100
- **AI**：会使用下蹲防御，分简单/普通/困难三档
- **地图 4 张**：🌿 草地 / ❄️ 雪地 / 🌇 黄昏 / 🌙 夜晚（背景简洁清爽，全 Canvas 绘制）
- **掉落物 8 种**：💣 炸弹 · 🛡 护盾 · ❤ 红心 · 💉 血包 · ⛓ 锁链 · 🛹 滑板 · ⚡ 双倍伤害 · 💰 金币
- **打击感**：命中顿帧、屏幕震动、连击计数、击杀慢动作
- **开局**：角色从天而降快速落地（约 0.5 秒），落地后短暂无敌
