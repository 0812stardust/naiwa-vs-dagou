# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.5**。

## 玩法
- **P1**：A/D 移动 · W 跳跃（奶蛙可二段跳）· S 蹲防 · J 普攻 · K 大招 · M 放炸弹 · ESC 暂停
- **双人对战**：P2 使用 ← → ↑ ↓、`-` 普攻、`=` 大招、`[` 放炸弹
- **多层地图**：四张地图均有平台/箱子/梯子/蹦床，可跳上跳下、爬梯、弹跳，走出平台边缘会下落
- **角色差异化**：奶蛙=快攻+空中二段跳；大狗=高攻+击退强化+**每 15 秒一次暴击（伤害 +50%）**，双方血量均 100
- **AI 优化**：AI 会使用下蹲防御，并能通过梯子/平台追踪高处的目标（可达性寻路），分简单/普通/困难三档
- **地图 4 张**：🌿 草地 / ❄️ 雪地 / 🌇 黄昏 / 🌙 夜晚，背景大幅美化（树木、雪山、城市灯光、流星等，全 Canvas 绘制）
- **掉落物 8 种**：💣 炸弹 · 🛡 护盾 · ❤ 红心 · 💉 血包 · ⛓ 锁链 · 🛹 滑板 · ⚡ 双倍伤害 · 💰 金币
- **打击感**：命中顿帧、屏幕震动、连击计数、击杀慢动作
- **计分与成绩**、**训练模式**、**键位自定义**、**设备适配**（全屏/触屏/自适应）
