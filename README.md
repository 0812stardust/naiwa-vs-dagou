# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.1**。

## 玩法
- **A / D** 移动 · **W** 跳跃 · **S** 蹲下防御（受击只掉 20% 血、无硬直）
- **J** 普通攻击（7 伤害）· **K** 大招（15 伤害，冷却 5 秒）
- 大狗由 AI 控制：会追击、撤退、攻击、跳跃躲避，并根据距离与血量决定是否放大招
- 顶部血条下方显示爱心命数与大招冷却条；死亡后满血重生，存活方血量与位置不变
- 主菜单可进入「设置」调整命数（1–9）与音效开关

## 运行
直接双击 `奶蛙vs大狗.html` 用浏览器打开即可，无需联网、无需安装。
