# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.3**。

## 玩法
- **P1**：A/D 移动 · W 跳跃（奶蛙可二段跳）· S 蹲防 · J 普攻 · K 大招 · M 放炸弹 · ESC 暂停
- **双人对战**：P2 使用 ← → ↑ ↓ 移动/跳跃/蹲防，`-` 普攻，`=` 大招，`[` 放炸弹
- **角色差异化**：奶蛙=快攻（速度快、普攻 8、大招 22/3.5s、空中二段跳）；大狗=力量（血量 120、普攻 10、大招 30/6s、击退强化）
- **AI 难度**：设置里可选 简单/普通/困难，影响反应、出招与躲闪
- **地图 4 张**：🌿 草地 / ❄️ 雪地（移速 -20%）/ 🌇 黄昏 / 🌙 夜晚（纯视觉）
- **掉落物 8 种**：💣 炸弹 · 🛡 护盾 · ❤ 红心 · 💉 血包 · ⛓ 锁链 · 🛹 滑板 · ⚡ 双倍伤害 · 💰 金币；5 秒未拾取自动消失
- **打击感**：命中顿帧、屏幕震动、连击计数、击杀慢动作与"击倒！"提示
- **计分与成绩**：命中/击杀/拾取/胜利得分，localStorage 记录局数、胜场、最高连击等
- **训练模式**：打木桩练习连招，可随时重置木桩血量
- **键位设置**：主菜单 → 设置 → 键位设置，冲突高亮提示，自动保存
- **设备适配**：画布自适应缩放、全屏按钮、手机触屏虚拟按键（人机模式）
