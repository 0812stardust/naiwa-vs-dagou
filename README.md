# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.55**。

## 玩法
- **P1**：A/D 移动 · W 跳跃（奶蛙可二段跳）· S 蹲防 · J 普攻 · K 大招 · M 放炸弹 · ESC 暂停
- **双人对战**：P2 使用 ← → ↑ ↓、`-` 普攻、`=` 大招、`[` 放炸弹
- **多层地图**：四张地图均有平台与箱子，可跳上跳下、走出平台边缘下落（已移除梯子与蹦床）
- **角色差异化**：奶蛙=快攻+空中二段跳；大狗=高攻+击退强化+每 15 秒一次暴击（伤害 +50%），双方血量均 100
- **AI**：会使用下蹲防御，分简单/普通/困难三档
- **地图 4 张**：🌿 草地 / ❄️ 雪地 / 🌇 黄昏 / 🌙 夜晚（背景简洁清爽，全 Canvas 绘制）
- **掉落物 8 种**：💣 炸弹 · 🛡 护盾 · ❤ 红心 · 💉 血包 · ⛓ 锁链 · 🛹 滑板 · ⚡ 双倍伤害 · 💰 金币
- **打击感**：命中顿帧、屏幕震动、连击计数、击杀慢动作
- **开局**：角色从天而降快速落地（约 0.5 秒），落地后短暂无敌

## UI
v0.55 采用「米白/米黄 + 黑色文字」的简洁扁平风格：柔和渐变背景、白色圆角卡片、扁平按钮，所有界面一屏完整显示、无需滚动；开始界面为模式卡片+图标入口；地图选择为二级菜单。
