# 奶蛙 vs 大狗 🐸🐶

网页格斗小游戏（单文件 HTML + 本地素材），当前版本 **v0.55**。

## v0.6 新内容
- **空中攻击 / 下砸**：空中按 J 出空中攻击，空中 S+J 下砸俯冲
- **受身系统**：被击飞后按跳跃键翻滚脱身（带短暂无敌）
- **能量条大招**：命中/受击积攒能量，满 100% 才能放大招，节奏更有策略性
- **攻击后坐力**：普攻类后坐力 ×3、大招 ×5
- **结算统计页**：胜负后显示伤害/连击/拾取/击杀/得分明细 + 胜者特写
- **新手引导**：首次战斗显示按键提示动画
- **AI 用道具**：大狗会主动捡护盾/血包/炸弹并会用炸弹
- **训练模式增强**：木桩可切换站桩/反击/移动，并显示累计伤害
- **连击层级**：5/10/15 连击音效与特效逐级增强
- **虚空边界修复**：越过地面边缘立即坠入虚空死亡，不再能退回

## v0.7 视觉升级
- **四套主题配色**：设置里可选 马卡龙/赛博朋克/复古/黑白灰，作用于全部界面与战斗 HUD
- **UI 设计系统**：统一配色/圆角/阴影变量、按钮质感、SVG 手绘图标、卡片弹入动效
- **地图背景图**：草地/夜晚 2 张高品质插画背景（`bg/` 目录），配合代码视差层；雪地/黄昏仍为代码视差
- **动效**：开局 3-2-1 GO 倒计时、角色弹性形变（跳压缩/落地拉伸）、能量满发光、受击残影、边缘轻微雾化

## 玩法
- **虚空边界**：地图两端为虚空（与背景同色、无黑边），地面在边缘截止，被击退或走出边界会坠入虚空死亡并重生；视野可延伸至虚空
- **虚空边界**：地图两端为虚空（与背景同色、无黑边），地面在边缘截止，被击退或走出边界会坠入虚空死亡并重生；视野可延伸至虚空
- **虚空边界**：地图两端为虚空（与背景同色、无黑边），地面在边缘截止，被击退或走出边界会坠入虚空死亡并重生；视野可延伸至虚空
- **打击感增强**：击杀时目标被击飞、攻击者受到后坐力，命中带火花与受击白闪
- **P1**：A/D 移动 · W 跳跃（奶蛙可二段跳）· S 蹲防 · J 普攻 · K 大招 · M 放炸弹 · ESC 暂停
- **双人对战**：P2 使用 ← → ↑ ↓、`-` 普攻、`=` 大招、`[` 放炸弹
- **多层地图**：四张地图均有平台与箱子，可跳上跳下、走出平台边缘下落（已移除梯子与蹦床）
- **角色差异化**：奶蛙=快攻+空中二段跳；大狗=高攻+击退强化+每 15 秒一次暴击（伤害 +50%），双方血量均 100
- **AI**：会使用下蹲防御，分简单/普通/困难三档
- **地图 4 张**：🌿 草地 / ❄️ 雪地 / 🌇 黄昏 / 🌙 夜晚（背景简洁清爽，全 Canvas 绘制）
- **掉落物 8 种**：💣 炸弹 · 🛡 护盾 · ❤ 红心 · 💉 血包 · ⛓ 锁链 · 🛹 滑板 · ⚡ 双倍伤害 · 💰 金币
- **打击感**：命中顿帧、屏幕震动、连击计数、击杀慢动作
- **开局**：角色从天而降快速落地（约 0.5 秒），落地后短暂无敌
